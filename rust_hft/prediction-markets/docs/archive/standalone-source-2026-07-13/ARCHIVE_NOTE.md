# Historical standalone PLOY README

`README.md` in this directory is the byte-for-byte upstream README from PLOY
`8ce4e0f150173a44030294101f4b1371cbdf80bc`.

The upstream `ploy-openclaw/` bytes are preserved from that source commit. Its
write-capable `workspace/AGENTS.md` is retained as `workspace/AGENTS.upstream.md`;
the active-name sibling is a Monday safety guard and is recorded in
`MIGRATION_ADAPTATIONS.md`. The package must not be copied back into an active Monday
path.

It describes the former standalone repository, including live execution, deployment,
local PostgreSQL, and legacy workflow instructions. Those instructions are historical
and are not valid entrypoints for the PLOY workspace inside Monday.
