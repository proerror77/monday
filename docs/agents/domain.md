# Domain Docs

This repository uses a single-context domain-doc layout.

Before exploring, read root `CONTEXT.md` and relevant ADRs under `docs/adr/` when they exist. If they do not exist, proceed silently; domain-modeling creates them only when the project resolves vocabulary or architectural decisions worth recording.

Use vocabulary defined in `CONTEXT.md`. Surface conflicts with an existing ADR instead of silently overriding it.
