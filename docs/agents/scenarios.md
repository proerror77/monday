# Task and symptom navigation

Choose the row matching the requested outcome, then follow the linked contract.
This map supplies navigation, not grants, live status, or an automatic repair
controller. [AGENTS.md](../../AGENTS.md) owns authority and delivery policy.
Record the relevant source, input and target identities before drawing a
conclusion; placeholders in runbooks are not runnable authority.

| Task or symptom | Required context | Entry and existing procedure | Evidence and stop point |
| --- | --- | --- | --- |

Parallel slices use `task-batch` on the lease/task admission path. | Stop. Do not provision AX or Substrate, and do not deploy them onto ACK. [#1216](https://github.com/proerror77/monday/issues/1216) is closed. |
| “Did this research run finish?” | Campaign/Mission ID, input window, source/image and expected terminal artifact | [Research evidence audit](../../.agents/skills/monday-research-evidence-audit/SKILL.md); [Campaign execution and recovery](../research/CAMPAIGN_WORKFLOW.md#execution-and-recovery) | Check terminal result, settlement and independent artifact readback for the same identities. Report negative/no-candidate separately from missing evidence. Submission or Job completion alone is insufficient. |
| “The model has IC but no trades” | Existing admitted calendar, fitted model, decision policy and result hashes | [H1 zero-trade diagnosis](../research/H1_ZERO_TRADE_DIAGNOSIS.md); [holding/accounting contract](../research/HOLD_TO_HORIZON_CONTRACT.md); [diagnostic implementation](../../rust_hft/alpha-harness/engine/src/prediction_diagnostics.rs) | Compare eligible forecasts with per-row costs and retain verified diagnostics. Missing historical diagnostics stay missing; a new readback must remain within authorized views/resources. Diagnosis does not change costs, horizons or open holdout. |
| “Run or resume this bounded CEX comparison” | Frozen target/evaluation, input receipts, trial/resource/deadline grant, source/image and one ACK controller | [Campaign preparation](../research/CAMPAIGN_PREPARATION_REUSE.md) → [native workflow](../research/CAMPAIGN_WORKFLOW.md) → canonical freeze/finalize/dispatch/generated execute | Recover recorded stages and Job UID; retain consumed trials and original deadline. Each search Campaign stops pre-holdout; [closed-family final evaluation](../../deployment/aliyun/research/README.md#final-evaluation-of-a-closed-family) requires its separate contract. |
| “Collector alert / stale data / upload backlog” | Alert or issue, exact host/lane, deployed identity and sample time | [Health script contract](../../deployment/aliyun/README.md#health-script-contract): on the named host, `/opt/monday/bin/monday-collector-health.sh --json --dry-run`; [monitor issue routing](../../deployment/aliyun/README.md#github-actions-workflow-fallback) | Inspect the reported breach and retained lane/OSS evidence. Dry-run avoids consuming persistent delta state. Process health is not dataset admission. Repair or cutover follows the owning lane's contract and independent readback; the alert itself supplies neither a writer nor a completed fix. |
| “Fix a behavior and deliver its PR” | Observable acceptance case, base/head, one writer and allowed files | [Task handoff](cursor-codex-handoff.md), [issue/PR lifecycle](issue-tracker.md), [focused validation](../../AGENTS.md#focused-validation), [publication policy](publication.md) when applicable | Reproduce, change, run the nearest useful check, review the actual diff, then follow the assigned endpoint. [Delivery status](../../.agents/skills/monday-delivery-status/SKILL.md) verifies requested Code/CI/Merge/Release/Runtime/Readback states independently. A merge does not close a runtime outcome. |
| “Market-data hot path became slower” | Same input/workload, host/toolchain, build profile and baseline/candidate source; identify the affected stage | [Hot-path architecture](../../rust_hft/docs/architecture/MARKET_DATA_HOT_PATH.md); [engine benchmark targets](../../rust_hft/market-core/engine/Cargo.toml) and [Binance parser target](../../rust_hft/data-pipelines/adapters/adapter-binance/Cargo.toml). From `rust_hft/`, choose the affected target, e.g. `cargo bench --locked -p hft-engine --bench binance_md_hotpath` | Retain comparable benchmark output and verify the affected runtime behavior separately where requested. Microbenchmarks do not prove end-to-end latency or production improvement. Missing production profiling access is an observability gap; it does not justify changing risk gates. |
| “Research is slow or uses too much memory” | Exact run/stage, observed durations/memory, current trainer, image, resources and budget | [Training verification](../research/TRAINING_STOP_AND_VERIFICATION.md), [bounded-run memory evidence](../../deployment/aliyun/research/README.md#memory-evidence-for-a-bounded-research-run), [ACK accelerator contract](../research/ACK_RESEARCH_ACCELERATOR.md). Remote compilation uses [monday-remote-build](../../.agents/skills/monday-remote-build/SKILL.md) | Distinguish admission, fitting, verification and upload costs before changing the program. Record comparable resource evidence. Current CPU/ndarray work cannot be made GPU work by changing a Job resource; a new experiment or accelerator must satisfy its own frozen contract. |

For module placement or vocabulary, use [domain docs](domain.md) and the
[repository map](../architecture/REPOSITORY_LAYOUT.md). For an unfamiliar
symptom, trace the owning implementation and nearest test, then add a scenario
link only when a reusable path is established. Promote a repeated correction
into the owning type, invariant, test or check when that can enforce it; keep
this page focused on finding those capabilities.
